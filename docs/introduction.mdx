## 是什么

ContiNew Admin（Continue New Admin）是一个多租户中后台管理系统框架，前后端分离。后端基于 Spring Boot 3（Java 17），依赖自上而下为 `continew-server` → `continew-system` → `continew-common` 的 Maven 多模块工程；前端为独立仓库 [continew-admin-ui](https://github.com/continew-org/continew-admin-ui)，基于 Vue 3、Arco Design、TypeScript 与 Vite。启动类为 `top.continew.admin.ContiNewAdminApplication`，dev 环境端口 8000。

框架的通用基础能力（CRUD 套件、认证、租户、数据权限、缓存、日志等）抽离在 [ContiNew Starter](/docs/starter) 中，以 BOM 方式引入（2.17.0），Admin 在其上做业务实现与工程级扩展。

## 解决什么问题

中后台项目的重复工作集中在权限模型、认证会话、文件存储、日志审计、任务调度这些横切能力上。ContiNew Admin 给出一套已经组合好且经过生产验证的默认实现，让新项目的起点是业务代码，而不是脚手架代码。

已经内置并开箱可用的功能包括用户、角色、菜单、部门、字典、参数配置、通知公告、文件管理（回收站与分片上传）、存储配置、短信配置、客户端配置、在线用户、登录与操作日志、多租户与租户套餐、AK/SK 能力开放、任务调度、代码生成。功能清单与使用方式见[功能手册](/docs/admin/manual/system)。

## 核心特性

**多租户行级隔离**：基于 ContiNew Starter 的 `continew-starter-extension-tenant-mp`（MyBatis-Plus 行级隔离），租户 ID 经 `X-Tenant-Id` 请求头传递，默认租户 ID 为 0。租户管理、套餐管理由 `continew-plugin-tenant` 插件提供。

**认证与多方式登录**：基于 Sa-Token（1.45.0）+ JWT，Token 名 `Authorization`。内置账号密码、邮箱验证码、手机验证码、JustAuth 第三方登录四种处理器。自 4.2.0-SNAPSHOT 起引入 `continew-starter-auth-refresh-token`，采用 Access Token（内存持有）+ Refresh Token（HttpOnly Cookie）双令牌轮换。Token 有效期在「客户端配置」页面按端动态管理。

**数据权限**：基于 `continew-starter-extension-datapermission-mp`，Mapper 继承 `DataPermissionMapper`（`continew-common` 的 `base/mapper` 包），由 `DefaultDataPermissionUserDataProvider` 提供当前用户数据范围，角色与部门的数据权限关联存于 `sys_role_dept` 表。

**CRUD 套件**：Controller 标注 `@CrudRequestMapping` 并继承 `BaseController`，`BaseController.preHandle` 按 API 类型自动生成并校验权限码。例如 `POST /system/user` 自动要求 `system:user:create` 权限，无需手写鉴权注解。该套件由 ContiNew Starter 提供，完整说明见 [CRUD 套件文档](/docs/starter/modules/extension/crud)。

**可插拔插件**：能力开放（AK/SK 签名）、多租户、任务调度（Snail Job）、代码生成器四个功能以 `continew-plugin` 下的独立模块交付，可按需引入或裁剪。任务调度默认关闭（`snail-job.enabled: false`），生产配置默认开启。

**代码生成器**：连接数据库表生成后端 Controller/Service/Mapper/Entity 等 11 个模板与前端列表页、新增弹窗、详情抽屉等 4 个模板，产物与现有分层约定一致，生成后即可参与 CRUD 权限体系。

## 技术栈基线

后端（第三方依赖版本统一由父 POM ContiNew Starter 的依赖管理供给，根 `pom.xml` 的 parent 指向 `top.continew.starter:continew-starter`）：

| 依赖 | 版本 |
|:-----|:-----|
| Spring Boot | 3.5.16 |
| JDK | 17 |
| ContiNew Starter（BOM） | 2.17.0 |
| Sa-Token | 1.45.0 |
| MyBatis Plus | 3.5.17 |
| Liquibase | 4.31.1 |
| JetCache | 2.7.9 |
| Redisson | 3.52.0 |
| CosID | 2.13.3 |
| FastExcel | 1.3.0 |
| Snail Job | 1.10.0 |
| X File Storage | 2.3.0 |
| SMS4J | 3.3.5 |
| JustAuth | 1.16.7 |
| Crane4j | 2.10.0 |
| Hutool | 5.8.47 |

前端（版本取自 `continew-admin-ui` 的 `package.json`）：

| 依赖 | 版本 |
|:-----|:-----|
| Vue | 3.5.4 |
| Arco Design（@arco-design/web-vue） | 2.57.0 |
| TypeScript | 5.0.4 |
| Vite | 5.1.5 |
| vue-router | 4.3.3 |
| Pinia | 2.0.16 |
| pnpm | 9.3.0 |

运行环境要求（JDK 17 为 Spring Boot 3 的最低要求）：JDK 17、MySQL 8.0.42（亦支持 PostgreSQL，脚本位于 `db/changelog/postgresql`）、Redis 7.2.8、Maven 3.9+（仓库内置 `mvnw`）。
