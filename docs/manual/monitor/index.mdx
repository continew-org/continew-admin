description: 系统监控模块提供在线用户会话管理与登录、操作日志的查询审计能力，本节介绍各子功能的定位与入口。

系统监控模块面向管理员提供两类能力：查看当前在线的登录会话并支持强退，查询审计登录日志与操作日志。对应一级菜单「系统监控」（菜单 ID 2000），前端页面位于 `src/views/monitor/`。
