ContiNew Admin 前端在本仓库的 `continew-ui/` 目录，是一套 React 19 单页应用，经 REST 接口与后端交互。本分组按主题讲解前端工程的封装机制（请求、路由、权限、组件、字典、布局），帮助你在既有约定下开发新页面。

## 技术栈

| 技术 | 版本 | 用途 |
|:-----|:-----|:-----|
| React | 19.3.1 | 框架 |
| Vite | 8.0.5 | 构建工具，dev server 端口经 `VITE_APP_PORT` 配置（默认 5173） |
| TypeScript | 7.0.2 | 类型系统 |
| Tailwind CSS | 4.3.3 | 样式，主题走 CSS 变量（`src/styles/globals.css`） |
| shadcn/ui（`@shadcn/react`） | 0.3.1 | 组件库，base-nova 风格，原语基于 Base UI 1.9.0，图标 lucide-react 1.55.0；组件源码经 CLI 拷贝在 `src/components/ui/` |
| TanStack Router | 1.170.46 | 路由，文件路由：`src/routes/` 目录即路由表 |
| TanStack Query | 5.105.0 | 服务端状态：请求、缓存、失效 |
| TanStack Table | 9.3.1 | 表格，列表页数据网格 |
| TanStack Form | 1.33.5 | 表单状态 |
| zustand | 5.0.16 | 客户端状态（认证、页签、外观偏好） |
| zod | 4.6.7 | 数据校验 |
| oxlint / oxfmt | 1.90.0 / 0.75.0 | 代码检查与格式化 |
| vitest | 5.1.0 | 单元测试（用例在 `continew-ui/tests/`） |

包管理器为 pnpm。常用脚本来自 `continew-ui/package.json`：

```bash
pnpm install      # 安装依赖
pnpm dev          # 开发服务器（默认 5173，/api 前缀经 Vite 代理转发到 http://localhost:8000）
pnpm build        # 生产构建（仅 vite build，类型检查是独立脚本）
pnpm typecheck    # 类型检查（tsc --noEmit）
pnpm lint         # 代码检查（oxlint）
pnpm fmt          # 代码格式化（oxfmt）
pnpm test         # 单元测试（vitest run）
pnpm preview      # 本地预览构建产物
```

`pnpm build` 不做类型检查，提交前把 `pnpm typecheck`、`pnpm lint`、`pnpm test` 跑一遍再推代码。

## 源码目录

`src/` 下的目录职责与路径别名约定见 [项目结构](/docs/admin/development/backend/structure)，那里有一份完整的目录树。写代码前要知道的三条：路径别名 `@` 指向 `src`（`tsconfig.json` 的 `paths` 与 `vite.config.ts` 的 `tsconfigPaths` 配合生效）；API 定义按后端模块放 `src/lib/api/`；页面放 `src/routes/`，目录位置就是访问路径。

## 环境变量

环境变量文件是 `continew-ui/.env.development` 与 `continew-ui/.env.production`，前者服务本地开发（接口走 `/api` 前缀，由 Vite 代理转发），后者服务生产构建（接口直连 `VITE_API_BASE_URL` 指向的域名）。完整变量清单与取值见 [环境变量参考](/docs/admin/reference/environment)，本页不重复列表。
