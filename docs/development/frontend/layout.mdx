调整全局外观、或想给布局加一个新偏好项时，读这页。布局与外观由两层组成：`src/components/app-shell/` 下的 `AppShell` 按 6 种布局模式渲染页面骨架，`src/lib/preferences/` 的偏好注册表管理 40 余项外观偏好，用户在右上角设置面板里的修改即时生效并持久化。

## 偏好注册表

外观偏好的单一事实源是 `src/lib/preferences/preferences-config.ts` 的 `PREFERENCE_REGISTRY`。每一项声明类型（枚举/数字/布尔/文本）、默认值、保存方式与作用到 DOM 的方式。

保存方式分三类。

| 方式 | 范围 | 说明 |
|:-----|:-----|:-----|
| `client-cookie` | 布局关键项（主题模式、主题色、内容布局、导航栏样式、侧栏形态、圆角） | 写入 Cookie，刷新首帧前就能读到，避免闪烁 |
| `localStorage` | 其余偏好 | 键名加 `pref_` 前缀 |
| `none` | 不保存 | 刷新即回到默认值 |

作用方式也分两类：`attribute` 写到 `<html data-*>` 供 CSS 选择器匹配（如 `data-theme-mode`、`data-radius`），`cssVar` 写到 `<html style>` 上的自定义属性（如 `--app-font-size`、`--app-tabbar-height`）。运行时写入走 `src/lib/preferences/preference-runtime.ts` 的 `applyPreference`，状态在 zustand 的 `src/stores/preferences/preferences-store.ts`（`usePreferencesStore`）。

首帧防闪烁由注入脚本承担：`src/scripts/theme-boot-script.ts` 生成一段内联 JS，`vite.config.ts` 的 `themeBootPlugin` 把它替换进 `index.html` 的 `<!--theme-boot-->` 占位处，首帧渲染前就把 Cookie/localStorage 里的偏好写到 DOM 上。新增偏好时注册表是唯一要改的地方，boot 脚本直接复用同一份注册表数据。

## 布局模式

布局模式偏好 `layout` 在一套 `AppShell` 里切换，共 6 种（`src/lib/preferences/layout.ts:55`），默认 `sidebar-nav`。

| 值 | 形态 |
|:---|:-----|
| `sidebar-nav` | 垂直：左侧菜单 |
| `sidebar-mixed-nav` | 双列菜单：一级窄栏 + 二级菜单栏 |
| `header-nav` | 水平：菜单全部在顶部 |
| `header-sidebar-nav` | 顶部通栏 + 侧边导航 |
| `mixed-nav` | 混合垂直：顶部一级 + 左侧子菜单共存 |
| `header-mixed-nav` | 混合双列：双列与水平菜单共存 |

`AppShell`（`src/components/app-shell/index.tsx`）按模式与 `navigation_split`、`header_menu_align` 等偏好算出侧栏形态、头部位置与头部菜单行为，渲染对应的头部、侧栏与内容区。侧栏本身有 `sidebar_variant`（sidebar / inset / floating）与 `sidebar_collapsible`（icon / offcanvas）两种形态偏好，值在路由 loader 里经 `src/lib/shell-preferences.ts` 从 Cookie 读出，保证首帧就是正确的侧栏状态。

头部组件在 `app-shell/header/`（菜单、搜索、通知、主题切换、用户菜单、布局设置入口），侧栏在 `app-shell/sidebar/`，页签栏在 `app-shell/tabbar/`。

## 主题与暗色模式

主题机制建立在 Tailwind CSS 4 的 CSS 变量上（`src/styles/globals.css`）。

暗色模式的开关是 `theme_mode`（light / dark / system，默认 light）。`applyThemeMode`（`src/lib/preferences/theme-utils.ts`）按选择解析出实际模式：`system` 跟随 `prefers-color-scheme` 并订阅系统变化，然后切换 `<html>` 上的 `dark` class 与 `colorScheme`。CSS 侧用 `@custom-variant dark (&:is(.dark *))` 声明暗色变体，`.dark` 选择器块整体覆盖变量值。切换时会临时加 `disable-transitions` class 压掉过渡动画，避免切换瞬间的颜色渐变。

主题色是 `theme_color`，10 个预置色（`src/lib/preferences/theme.ts`，中文名：霁蓝、墨染、天青、竹青、琥珀、丹霞、朱砂、霓虹、暮紫、石板），经 `<html data-theme-color>` 匹配 `src/styles/theme-colors.css` 里的变量组。色值是按亮暗两态调好的 oklch 值，主题色只覆盖品牌相关 token，与暗色模式正交叠加。没有运行时色阶生成，想加一个新主题色就在 `theme-colors.css` 里加一组变量。

配套的外观开关：灰度模式（`data-color-gray`，`filter: grayscale(100%)`）与色弱模式（`data-color-weak`，`filter: invert(80%)`）可叠加（`src/styles/globals.css:258`）；圆角偏好按基础值的比例缩放（0 到 1）；字号偏好（14 到 18px）驱动整套 rem 字号体系。动画基础样式来自 `tw-animate-css`。

## 设置面板

右上角齿轮图标打开设置抽屉（`src/components/app-shell/header/layout-controls.tsx`），内部分七个区块：主题、其他、布局、标签栏、通用、小部件、快捷键。改动经 `usePreferencesStore` 即时写 DOM 并持久化。快捷键区块展示全局快捷键（`app-shell/global-shortcuts.tsx`，可在偏好里逐项停用）。

## 站点信息与页面效果

站点标题、Logo、版权、备案号由后端「网站配置」维护，前端经 `src/hooks/use-site-options.ts` 调 `GET /system/common/dict/option/site` 拉取（结果缓存在 `src/lib/site-option-cache.ts`）。改站点名不用动前端代码。

页面级效果集中在 `app-shell/page-effects.tsx`：

- **动态标题**（`app_dynamic_title`）：标签页标题按「页面名 - 站点名」拼出；
- **水印**（`app_watermark` + `app_watermark_content`）：平铺水印层绘制用户名与当前时间，内容留空时显示用户名；
- **更新检测**（`app_enable_check_updates`，仅生产构建生效）：页面可见时每 5 分钟拉一次 `index.html`，入口脚本地址变了就在右下角提示「发现新版本」并引导刷新。

锁屏在 `app-shell/workspace-overlays.tsx`：解锁密码是锁屏时本地设置的口令，SHA-256 后存 sessionStorage，仅用于遮蔽无人值守的屏幕，不参与认证。
